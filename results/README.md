# Retrieval eval outputs

Generated by `python scripts/run_retrieval_eval.py` (or `python -m evidence_retrieval eval`).

| File | Contents |
| --- | --- |
| `retrieval_metrics.csv` | TF-IDF vs dense vs hybrid on the same title→passage queries |
| `retrieval_ablations.csv` | Chunk size / field / method ablations |
| `retrieval_eval_detail.csv` | Per-query ranks + leakage signals |
| `qualitative_failures.md` | Sampled misses / opposite-label / same-subject cases |
| `eval_queries.csv` | Query set used for the main table |
| `workflow_comparison.csv` | Optional classify-then vs retrieve-first demo rows |
| `retrieval_eval_meta.json` | Protocol note |

Do not hand-edit metric CSVs — regenerate them with `python scripts/run_retrieval_eval.py`,
then `python scripts/update_readme_metrics.py` (also invoked at the end of `eval`).
